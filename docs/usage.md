## 按模式选入口

| 你手头有什么 | 选哪个模式 | 这一步拿到什么 |
| --- | --- | --- |
| 一份想借鉴的 PPTX、PDF 或截图 | [Extract · 提取设计](#extract--提取设计) | 素材清单、组件覆盖表、经审阅的设计包 ZIP |
| 一个设计包和一份新文稿，想先看怎么排 | [Reuse · 选版与填槽](#reuse--选版与填槽) | 逐页分镜、匹配到的版式、需要调整的页面及原因 |
| 一个设计包和确认稿，准备制作和交付 | [Make · 编辑与导出](#make--编辑与导出) | 本机编辑页、可编辑 PPTX、16:9 PDF，或可离线编辑的 HTML |

第一次用，可把参考稿和文稿放进同一个工作目录，安装完整的 Skill 文件夹，然后在 Codex 里使用 `$ppt-design-system`。也可以让 Agent 直接读取仓库中的 [SKILL.md](../ppt-design-system/SKILL.md)。 [快速开始](../README.md#quick-start--快速开始)

### Extract · 提取设计

提供参考文件和常见用途。如果最在意章节色、某种排版或可单独复用的贴纸，直接点名。

> 用 `$ppt-design-system` 提取这份参考。我之后会做内部项目评审，需要两项对照、阶段行动与验收。请列出可单独取出的素材、组件覆盖和需要补足的版式，最后给我设计包 ZIP。

先看素材清单和代表页，再确认哪些是固定装饰、哪些随新稿替换。PPTX 可以扫描对象与内嵌媒体，PDF 可以登记可取得的图流。截图用于观察和重建可见结构，独立图层和原字体的身份需要额外来源。 [提取步骤](../ppt-design-system/references/workflow.md#自动生成素材清单和覆盖表)

### Reuse · 选版与填槽

提供设计包 ZIP 和文稿。文稿可以是逐页要点或连续文字，由 Agent 整理成制作所需的语义文稿。标明必须保留的数字、限制条件和页序。

> 用这个设计包为新文稿出逐页分镜。每页列出内容关系、选中的版式和取舍理由。遇到容量或结构不匹配，告诉我是换版、拆页，还是需要补组件。

审阅时先看标题能否连成主线，再看对照、顺序或因果有没有用对构图。若有版式缺口，可在副本补足后再进入制作。 [匹配与延展](../ppt-design-system/references/element-compilation.md#3-读稿匹配和延展)

### Make · 编辑与导出

提供设计包、确认稿和要放进演示的内容图片，选择本机编辑页或离线文件。

> 用这个设计包和确认稿打开本机编辑页。我会改几处文字和图片，最终从页面下载 PPTX 和 PDF。

1. 打开 Agent 给出的本机链接。点选画布上的标题、图片或组件，也可以从侧栏选择。
2. 在侧栏改字或换图。拖动组件调整位置，拖右下角控制点缩放。需要回退时点「撤销」。
3. 从右上角「导出」选「可编辑 PPTX」或「PDF」。两种格式都取点击时的编辑状态。打开 PPTX 检查关键文字、图片和组件能否继续加工，打开 PDF 检查页序和裁切。
4. 如果要把网页带走，选「另存 HTML」。该文件带着修改，双击即可离线播放和编辑。直接下载 PPTX 和 PDF 使用本机编辑页，PDF 导出还需要 Node.js、Playwright 和 Chromium。

PPTX 支持文字、图片、基础形状、直线箭头和组件分组。复杂曲线可走 HTML 或 PDF，原生表格和图表暂未接入。 [本机启动与导出命令](../ppt-design-system/references/workflow.md#在编辑页直接导出)

## 跟着做一次 · 三章十页的图书归还试点

| 步骤 | 怎么做 | 看什么结果 |
| --- | --- | --- |
| 1. 准备输入 | 放入一套参考和确认稿。把内容分成「归还入口」「收件与归档」「行动与验收」三章。 | 确认哪些内容已定，哪些图片是示意。 |
| 2. 提取设计 | 让 Agent 从参考拆出章节页、同级三栏和白底说明页，登记各自的用色与用途。 | 拿到素材清单、覆盖表和设计包。 |
| 3. 核对分镜 | 用章节页开启新主题，用三栏并列三种收件状态，用阶段组件列出行动和验收。 | 看章节用色和版式是否随内容任务出现，核对缺口。 |
| 4. 打开编辑页 | 改第 2 页标题，换第 4 页的图，拖动第 9 页的阶段组件。 | 预览即时更新，可以撤销最近一次修改。 |
| 5. 交付两份文件 | 从同一个「导出」菜单下载 PPTX 和 PDF。 | 两个文件都保留三处修改。PDF 一页一张，PPTX 可在 PowerPoint 里继续改标题。 |

这个流程曾用 Wikimedia 风格设计包和中性文稿验证。绿色用于三张章节页和一张绿蓝白三栏，改字、换图及组件移动都进入了十页 PPTX 和 PDF。可用自己的参考和文稿按同样步骤运行。
