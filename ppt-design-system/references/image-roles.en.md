# Decide the image's role on the page first

**English** | [简体中文](image-roles.md)

For a brand/IP style description without a concrete reference, use the [selection entry](style-selection.en.md) to resolve direct original imagery versus independent similar-style assets. Make the role decisions below within that choice; naming a style does not select original images for use.

Before searching, retaining an image slot or extending a layout, compare the reference with the new page's task. Ask: “If this were removed or replaced by a simple component, what information, focal point or transition would the reader lose?” Frames, bitmap formats and screenshot resolution describe the medium, not the role.

| What the page must preserve | Preferred action |
| --- | --- |
| **A real object or evidence:** a specific place, product, person, process, site or project state. | Try user originals, independently extracted source media or approved pack photos of the same subject. If missing, check official/original photographic sources for identity, context and permission. Similar stock/generated images are suitable only when explicitly illustrative and appropriate to the copy/use. |
| **Photographic visual language:** space, light or material is central to an opening/transition; exact location can change. | Try suitable existing photos and actual crops first. If missing, [search in Chinese and English](photo-sourcing.en.md) by subject, text-safe space, aspect and target pixels. Clearly labeled generated imagery is an option for atmosphere when the manuscript permits it. |
| **Artistic expression or layout structure:** fields, collage, abstract painting, textures, icons or backdrops supply style, grouping, emphasis or rhythm. | Reuse clear suitable art/components first. Without originals, extend contours, color, texture, overlap and rhythm using native shapes, motifs or original illustration. Complex effects may use separate original images, keeping typography independent. Optional decoration can be removed and whitespace rebalanced. A specific artwork presented as content needs source/rights verification. |
| **Verifiable quantities, relationships or processes:** charts, tables or diagrams embedded as images. | Preserve composition, colors, annotations and reading order, then redraw from confirmed new data/relationships. Reuse existing charts/components before adding structure. State the actual editable scope. |

One page can contain several roles. A new left-photo/right-copy case page may still need a real project photo. The same card can use a color field for grouping or a cropped approved photo to continue the cover's chapter atmosphere; its role depends on the manuscript.

For affected pages/slots, keep a row in `STYLE.md` or production records: **page / reference page or layer / role / decision / acceptance evidence**. Retain source, identity, crop comparisons or data checks. For conflicting/uncertain references, record reasons and preserve a replaceable composition.

Use Extract's [per-page image decisions](workflow.en.md#automatic-asset-inventory-and-component-coverage) as a draft, then record final choices and unresolved items. Extracted streams, object types and matched captions are scanning evidence; identity, rights, crop and visual completeness still require role-based review.

### Three decisions within one report

- **Full-bleed fog-forest cover:** photographic depth and dark regions carry the opening. Without a high-resolution original, inspect usable real photos and expand crop-compatible candidates with bilingual queries.
- **4:3 chapter image card:** continue the photographic atmosphere. Reuse a qualified original if its subject survives the actual crop. A label-only card can extend an existing card surface.
- **Data trend page:** the chart carries monthly readings. Draw from new data, retaining the report's white plot area, insight sidebar and green emphasis.
