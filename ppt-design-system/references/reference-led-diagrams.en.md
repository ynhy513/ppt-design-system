# Reference-led diagram design

**English** | [简体中文](reference-led-diagrams.md)

The user-selected reference determines visual language. Record purpose/evidence from actual sources, including white, colorful, geometric or illustrated treatments. “Serious” or “creative” can describe appearance, but selection depends on observed traits and the relationship the page must explain.

## Extract usable treatments

Inspect representative pages/regions. Record page, exhibit or viewport and separate observations/extensions in pack evidence/rules.

| Dimension | Record | Decisions influenced |
| --- | --- | --- |
| Reading order/focus | Title/diagram placement, entry point, explanation/evidence distance | Diagram entrance, axes and emphasis |
| Contours/routes | Open/enclosed, hard/rounded, straight/polyline/curved, arrow placement | Rail, ring, grouping, curves or lines |
| Layout/density | Repeated axes, type hierarchy, bands, continuous space, label length/lines | Orientation, node size and overflow alternatives |
| Color/hierarchy | Background, regions, text and emphasis | Layer roles/contrast |
| Scope | Chapter, data exhibit, concept diagram or third-party logo/illustration | Rules transferable across pages versus local evidence |

The manuscript controls quantities, direction, ownership and count. An ascending reference curve can inspire connector shape/color rhythm for an unquantified sequence while retaining a horizontal baseline. Two low/high categories support a qualitative matrix; real coordinates require a verifiable quantitative chart.

## Produce and review

1. Strictly match first and retain gaps. Reuse source visual traits with the same copy. Mark new compositions as extensions, separating observations from added treatments.
2. Select drawing/capacity by relationship. Start with paired-state comparison or qualitative matrix when suitable; long copy, more dimensions or multiple items per quadrant need density variants. Confirm stages/groups/common dimensions before arrows/containers. Timeline intervals retain consistent axes/bar lengths.
3. Compare actual pages: identify which source treatment appears in which production region and whether adaptations changed meaning. Prioritize nodes, direction, axes, capacity, numbers and editability. Compare two renders when feasible.

## Multi-level ownership and cross-role handoffs

State the reader's question before comparing treatments preserving the same facts. When the original pack has an ownership/handoff gap, try these in production:

| Reader question | First candidate | Preserved relation/limits |
| --- | --- | --- |
| Who reports directly to whom? | Connected tree | Explicit parent/child endpoints; shared/cross-group roles separately labeled. |
| Which roles belong in each group? | Nested containers | Outer common scope and exclusive inner groups, readable names/members and separation. Multiple membership needs labeled links or grouped tables. |
| What responsibilities belong to a group? | Grouped table | Groups/children share a baseline; reserve a responsibility column if needed. |
| Who hands what to whom? | Swimlane | Each action belongs to a role/phase; arrow start/end/item explicit, vertical direction follows actual sender. No invented handoffs in unsupported cells. |
| What does each role do per phase? | Phase × role table | Two shared reading axes; retained handoffs explicitly name phase, sender, recipient and item. |
| Which backstage actions support the visible experience? | Service blueprint | Align user, frontstage, backstage and systems per phase. Visibility/dependencies come from the manuscript. |

Fix copy/style parameters when comparing and test whether readers can restate direct ownership, recipients and visibility. With another reference, recheck field/line/text contrast, long labels and compact placement. [Nested containers/swimlanes](structural-components.en.md#bind-nested-containers-and-swimlanes) received rendered review on two fictional manuscripts about community photographs and campus instrument sharing. Reconfirm sender/recipient/item from each new manuscript. Set capacity from measured glyph width, line counts, arrow space and placement; use role tables or splits above limits.
