# 整页构图规则

## 提炼

看同尺度的整页渲染，按视觉家族与页面职责选代表页。先标第一眼落点、信息主簇、次级区域和留白，再追溯到底层对象。用同类页确认哪些安排反复出现，用密集页、转场或相反构图核对适用边界。单页上的做法先记为该页型的观察。

| 观察项 | 记录什么 |
| --- | --- |
| 重心与留白 | 主簇落在哪边，主次区大致占比，什么给另一侧配重。对比内容的重要性、图文面积和实际视觉强度。 |
| 对齐与偏移 | 读者依靠哪些边、轴和间距比较信息。记录哪些物件有意错位、错落或倾斜，哪些数字、表头、正文或导航依赖稳定对齐。无明显偏移时记录原稿的网格纪律。 |
| 叠放与越界 | 哪一层压在前面，哪些物件可跨容器边界，哪些标题、标注、轴线或关键画面需要完整露出。 |
| 图片方向 | 图像在讲什么，是证据、人物反应、动作提示、材质还是情绪。记录主体、取景、视线或动作方向、裁切、留字区和位置，补充原稿反复出现的处理方式。 |
| 多页变化 | 哪些锚点跨页稳定，哪些要随讲述任务改变。观察图像占比、重心、信息密度以及转场前后的变化。 |
| 线条职责 | 分开记录贴着字基线的局部强调线与组织版面的分隔线。记录强调发生在标题、正文或哪一段词语，以及分隔线跨过的栏和起止点。 |

把风格形容词转成观察得到的动作。例如，「有社交感」可以来自表情近景、动态姿态和透明剪贴，适合需要表现参与、交流或动作的章节。图像具体做法以参考页为依据。透视造成的斜线、文件原生旋转和新稿旋转角度分别记录。

对会改变阅读层级或分组的细节，登记**来源区域、作用对象、绑定方式和变化条件**。例如，文字下划线绑定短语并跟随换行，底色条可能绑定整行或词组，栏间横线则绑定布局轴线和跨栏范围。对照同族样本中有无该细节的页面，区分普遍规则、页型变体和单页做法。

## 编译和选择

为每类构图记一条可用的规则，包含来源页和区域、适用的内容关系、第一眼落点、主次区相对位置、可偏移的图层、阅读保护区、图片的语义职责和替换条件。写清哪些关系固定，哪些可随内容密度和画幅变化。只有在多个同类样本支持时才推定通用范围。单页角度或宽度只作为该页的证据，新设范围标为延展。

在 `STYLE.md` 写规则，在配方的 `layout` 里引用规则和页面职责，再在 `pattern` 里落实图层尺寸、位置、顺序、旋转和图像槽。只需文字分镜时，在逐页方案里写出等效的位置和素材指令。

整页配方的字段不匹配时，仍可复用原包中已取证的局部构图。对逐行标题衬底这类强调图层，先按原包的位置、尺寸和文字内边距放入新稿，再检查每条衬底与对应标题的关系。文字放不下时，先用同族的字阶或分行变体；只有需要改动衬底时，才把改动登记为延展，并并排核对原参考、原包重放和当前成片。

和标题一起记录该页的主标题、次标题、正文与标签各自的字体族或替代字体、相对页宽的字号、字重、行高和对齐。把主次字号比、文字框与衬底的相对位置列为复用证据。截图只能估算时标为观察，原生 PPTX 和可读 PDF 优先使用源参数。先以原字阶试排，过长时优先分行。需要缩小某一文本层时，为该层记录调整理由和实测字号，沿用原字体族、字重和行高。

标题分行本身承担构图职责时，记录每行的角色、顺序和换行位置。双语封面使用稿件或已确认样张中的两种标题，按参考对齐并保留字阶。同字阶两行可在一个槽内用显式换行，字阶不同则各绑定一层。缺少可用译名时记录缺口，采用已评审的单语变体时写明依据。

### 检查沿用的标题与强调图层

保留冻结的原包作对照。在原有 Reuse 复验步骤登记每个选中版式。登记继承的主标题、次标题、正文和标签，连同对应的衬底或色块。整页是新构图但沿用了可核对的局部图层时，也登记这些图层。没有可比版式或局部构图时，在 `extensions` 说明参考证据和延展理由。产出版改了图层名时写 `target`。需调整文字容器时写四个百分比坐标 `box`，需缩小文字时写 `size`，并写明各自调整理由。检查比较实际字号、字重、行高、字族、对齐、框尺寸和位置、衬底颜色和相对叠放顺序。

衬底是纸片等图片时，登记对应图片层。校验同时比较固定素材指纹、填充方式和裁切位置。成片对照仍要检查字面是否落在衬底上的预期位置。

复用强识别度底色或固定母版底图时，在版式复验项写 `"background": true`，用原参考同页平坦区或原生填充定基准。制作核对底色及固定底图指纹。新排版只沿用底色时，`layers` 可为空，并记录新字号和位置的理由。即使继承校验通过，也要对照原图，避免把设计包旧有的可读性改色当作原色。

标题白条逐行衬着文字时，从原参考量每行的字面高度、衬条厚度、左轴及两侧留边。换文案时按新字面复验留边和阅读节奏，记录因字宽或行数变化重新测定的版式。固定宽度的槽框只用于参考确实有固定色场的版式。

独立强调线与标题共同构图时，也登记该线层。校验比较它的路径、描边颜色和粗细。

```json
{
  "source_system": "extracted/design-system.json",
  "reviews": {
    "adapted-cover": {
      "source_pattern": "blue-print-cover",
      "layers": {
        "title": {},
        "title-band": {},
        "subtitle-band": {},
        "subtitle": {"target": "caption", "size": 4.2, "reason": "较长的句子按原白条试排为两行。"}
      }
    }
  },
  "extensions": {
    "nested-ownership": "参考无层级关系版式，沿用参考的色阶复用所有权组件。"
  }
}
```

```bash
python ppt-design-system/scripts/make_deck.py production.zip manuscript.json \
  --inheritance-review inherited-layout.json --out new-run
```

`source_system` 相对于复验清单所在目录。缺记录或与已登记值不符时，制作会在渲染前停止。批量制作生成 `inheritance-report.json`，本地编辑页的启动命令也接受 `--inheritance-review`。只交付分镜时保留这份记录，成片时执行校验。并排检查原包重放和成片的实际字面大小、换行、字体替换和衬底的视觉重量。用代表页的主标题／正文及次标题／正文比值记录有意调整。

若标题的显式分行属于沿用的构图，给对应文字层登记 `"lines": 2` 等非空行数。双语分别占用两层时，分别登记每层的行数。Make 在填槽及加载编辑后核对文字分行和登记图层的最终位置。需要改变受保护的几何时，更新生产包和评审清单，再重建编辑基线。

用 `audit_replay.cjs` 检查同目录保留继承报告的静态 HTML。它会核对登记标题的实际渲染行数，发现长标题额外折行时报告页面和图层。按文案容量选择已评审的长标题变体或确认短标题，再重跑。语言顺序和译名仍用成片对照核对。

关键词下划线绑定文字图层的 `underline_slot`。适配新文稿时填写标题或正文中恰好出现一次的片段，或填写空字符串跳过强调。浏览器用原生文字下划线跟随字体与换行。独立分隔线用 `line` 图层，保留来源的轴线和跨栏范围。视觉复核分别检查两类线。

1. 先按章节关系、内容长度、比较维度和阅读顺序选候选版式。再按源稿的重心、对齐和图片规则选合适变体。内容项数相同的模板也可以有不同构图。
2. 允许同级内容采用不等宽容器时，明确用同字阶、同标签待遇或清晰顺序保住它们的同级关系。仅在源稿和页面职责都支持时使用错落、叠放或倾斜。
3. 根据[图像职责](image-roles.md)选择复用、搜图、延展或从数据绘制。核对该章的主体和落点。合适的原图依照实际用途进入固定素材或可换槽。画面可以省略时，重排留白和主次重量并记录延展。
4. 内容超出容量时，先尝试同风格的高密度变体，或在保住主焦点和阅读轴的前提下调整槽位。记录改变的关系及其原因。

## 验收

把源稿代表页与新稿放在同尺度比较。先看缩略图的第一眼落点、主次配重、留白和整套节奏，再在实际尺寸检查斜放边界、文字与图像遮挡、图像的叙事作用。浏览器通过代表技术检查通过。构图和素材方向的复现需要视觉评审。

每个用到的风格特征都应能对应到来源证据、新页上的具体做法和适用场景。至少检查一张能体现该家族特点的页面和一张内容密集的页面，素材范围允许时再用新内容或替换素材验证。关键特征有证据、适用于当前页面却在渲染中消失时，修正配方后重验。交付范围只含文档或分镜时，记录已完成的检查和待验证项。

复核局部细节时，把证据区域与新稿在阅读尺寸下并排。先核对作用对象，再用一个会改变位置或换行的内容变体复核绑定。例如，替换被强调的词组并使它跨行，检查下划线是否逐行跟字。检查独立横线时，核对共同轴线、起止点与跨栏范围。

## 对照示例

- **纸片拼贴式的并列观点**可以用偏置纸片和局部倾斜建立动势，同级短标题仍用统一字阶。适合交流和参与的章节可放表情近景剪贴。逐行对应的信息页保留横向阅读轴，斜放只用在衬底和短标签。
- **对齐卡片式的并列观点**沿用同级等宽卡和共同起线。拆解章节通过同一位置的定位图切换高亮。偏移和人物贴纸需要该家族的独立证据。
