# 只有风格描述时，先选择素材方式与视觉方向

[English](style-selection.en.md) | **简体中文**

适用于「死亡搁浅风格」「L’Oréal Groupe 风格」「轻快的编辑设计」等请求：用户尚未提供具体参考、设计规范或已批准设计包。它是进入现有 Extract / Reuse / Make 前的条件入口，不增加制作模式、命令参数或设计包字段。

已有明确文件、URL、设计包或本轮已选方向时，沿用该选择。仅因替换稿件、补一页、缺一张图，不重走整套确认。若用户明确委托自行决定或要求跳过选型，可做出并记录选择；单独说“开始”不等于跳过这两个选择。避免把未回复、默认勾选或等待超时视作选择。身份歧义会改变参考时，先用一句话区分品牌、集团或具体作品。

## 选择一：图片素材方式

提到品牌或 IP、且图片会承担封面、转场或内容职责时，先确认；既有明确授权和偏好可直接沿用。可先进行不依赖答案的参考检索与视觉观察，待素材方式明确后再制作使用图片的候选页。

> 图片你希望怎么处理？
> - 直接使用提到的品牌 / IP 的图片，例如官方剧照、场景或产品图。
> - 使用相似视觉语言的独立图片，例如相近光线、材质和构图的实拍或原创图。

只写「某 IP 风格」不能推断为选择原作图片。选择相似风格也不自动等于 AI 生图：按[图片职责](image-roles.md)判断复用、搜图或原创延展，再按已有[搜图规则](photo-sourcing.md)选源。若该页纯粹依赖字体、色块和结构，没有有意义的图片需求，不为了提问而加入图片，记录「不适用」后进入方向选择。非 IP 的泛风格描述不必询问不存在的 IP 素材选择。

图片方式可按页面或角色划定，例如「封面用官方图，内容页用独立素材」。把“看原图来理解风格”和“将原图放入交付物”分开：相似风格路线仍可观察官方参考，候选页和成稿则使用选定方式的素材。官方图来源与分发条件继续按现有资产规则记录；用户选用不改变素材的授权范围。相似图片不充当指定人物、产品、地点或事件的实证，不能在缺少证据时替换为貌似真实的案例图。

## 选择二：用可见预览选择视觉方向

1. **看真实参考再提方向。** 检索并实际查看适用的官方网页、公开报告、演示或其他可靠参考。对泛风格可选几种不同视觉家族；对品牌或 IP 可选其不同媒介、时期或页面职责。保存来源链接与代表区域，写清观察范围。无法取得或查看参考时说明缺口；自主方案标为设计提案，不冒充原版观察。
2. **通常给 2–3 个有差异的候选。** 方向需在字体层级、构图、图片处理、信息密度或图形节奏上存在可说明的区别。不能只换主色、圆角或原图。图片来源方式在各候选间保持与第一步一致，使两类选择互不混淆。
3. **用同一内容做小样并实际渲染。** 通常各做一张封面和一张代表内容页；稿中有数据时优先用同一张数据页作内容样本，没有数据不虚构数字。保持文案、事实和数据相同，通过分组、留白、构图与密度表达差异。没有确认稿时，用明确标注的同一占位内容。复用既有渲染链路，不提前制作整套成品。检查候选的可读性、文字容纳和图片裁切；清楚标注「原始参考」与「生成预览」，不能只给文字风格名或参考截图就宣称完成候选生成。
4. **展示并等待用户选择。** 一起呈现来源证据、生成预览、简短差异和适配取舍，再询问选哪一项。用轻量并排图或可离线查看的对照页即可；没有网页交付需求时不必另建选择器应用。可推荐一个方向并说明原因，但推荐不算用户已选。等待期间可整理稿件和来源，不冻结某一方向的正式包或制作整稿。
5. **允许组合，写明主次与作用范围。** 例如「A 的整体排版，B 只用于数据页」。用户说“A+B 结合”且范围未定时，依据已展示的差异给出具体主次并明示；只有歧义会实质改变设计时才补问。后续同一项目沿用选择；若用户改方向，在生产副本调整并保留原包。

候选展示可采用以下结构，具体方向应来自本次观察，不能固定套用这几个名字：

| 方向 | 原始证据 | 同稿生成预览 | 主要区别与取舍 |
| --- | --- | --- | --- |
| A · 编辑式 | 已查看的参考封面 / 内容区域 | 封面 + 内容页 | 标题、留白和色场节奏；长文适配方式 |
| B · 指标式 | 已查看的报告或演示图表 | 相同封面文案 + 相同内容 / 数据 | 数字层级、图表与注释密度 |
| C · 图片式（确有依据时） | 已查看的图文页面 | 相同内容，遵循已选素材方式 | 图片占比、裁切与章节转场 |

## 记录并接回既有流程

在生产目录的现有记录或 `style-selection.md` 中保留以下信息；它是 Agent 的选择记录，不是编译器新输入格式：

- 用户最初的描述、已知用途与具体实体。
- 素材方式：直接引用 / 相似风格 / 按页混合 / 不适用；适用页与用户选择依据。
- 候选 ID、实际参考链接及查看范围、生成预览的位置、已知未复现项。
- 用户选择或明确委托自行决定的原话；主方向、辅助方向及其作用范围。
- 后续 Extract 使用的参考、已继承项、延展项与待确认事项。

选中后，依据真实来源建立或复用设计包，按现有要求重放和冻结基线，再用生产副本做新稿。候选预览属于生产设计提案，不能反向当作“源参考原本就有”的证据。继续执行既有字体比例、标题衬底、色场、图片职责与可编辑性交付检查；这一步不更改其验收标准。
