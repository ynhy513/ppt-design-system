# 先判断图像在页面中的职责

在搜图、决定保留图片槽或延展版式之前，把参考画面的做法与新页面的任务对照。先问「拿掉或换成简单组件后，读者会失去哪条信息、哪个视觉焦点或哪种转场？」从页面任务和参考证据判断。图片框、位图格式和截图分辨率只能说明素材的载体。

| 页面需要保住什么 | 优先采取的动作 |
| --- | --- |
| **真实对象或证据。** 具体地点、产品、人物、工艺、现场或项目进度。 | 先找用户给的原图、参考的独立原件或设计包已批准的同一对象照片。仍缺时，向官方或原始拍摄来源查找，核对身份、上下文和许可。相似图库照或生图只能在文案明确改为示意且符合用途时使用。 |
| **摄影的画面语言。** 真实照片的空间层次、光线或材质是封面或转场的主要表达，具体地点可换。 | 先试已有合适照片及实际裁切。仍缺时按主体、留字区、画幅和目标像素[用中英文搜图](photo-sourcing.md)。图片仅作氛围且文稿允许时，可考虑明确标记的生成图。 |
| **艺术表达或版面结构。** 色块、拼贴、抽象绘画、纹理、图标、衬底主要负责风格、分组、强调或节奏。 | 先复用清晰且适用的艺术素材或已有组件。原件缺失时，沿用参考的轮廓、色彩、纹理、遮叠和节奏，用原生形状、共享图形或自制插画延展。复杂艺术效果可用独立原创图像，保留与排版的分离。纯装饰在删除后仍满足页面任务时，可省略并重新平衡留白。若页面要呈现某件特定艺术品，它承担的是内容，需核对作品来源或使用权。 |
| **可核对的数值、关系或流程。** 截图里的图表、表格、流程图可能是图片。 | 继承板式、颜色、注释位置和阅读顺序，用确认过的数据或关系重绘。先重用已有图表或组件，再补需要的结构。按实际输出说明可改范围。 |

同一页可有不同职责。例如把一个新案例页延展成「左图右文」后，左侧仍需搜真实项目照片。照片是否承担关键职责也随文稿变化，同一张卡片若只需要分组可收回为色块，若承担与封面呼应的章节转场则可裁切复用已批准的照片。

对受影响的页面或槽位，在 `STYLE.md` 或生产记录留一行 **页面 / 参考页或图层 / 职责 / 处理决定 / 验收依据**。留出素材来源、身份、裁切对比或数据核对证据。参考画面有冲突或无法确认时记录判断依据，保留可替换的构图。

### 同一份报告的三个判断

- **满幅雾林封面**。摄影的远近层次和暗部承担开场。参考截图无法提供高清原件时，先看可用实拍，再用双语关键词补齐可裁切的候选。
- **4:3 章节图片卡**。照片负责接续章节氛围。同一张合格的照片经实际裁切仍能保住主体，就复用。只承托标签的卡片可以延展已有卡面。
- **数据趋势页**。图表承载按月读数。从新数据画线，沿用报告的白色图区、侧栏洞察和绿系重点。
