# 多页视觉分镜

把参考稿的设计语言转成一套有前后关系的页面。输入可以是参考稿或已有的 `STYLE.md`，加上目标媒介、已有的叙事职责或页数约束。纯视觉阶段用「建立主题」「对照两项」「展示细节」等职责和图片、标题、图表占位槽来设计。文稿未定时，把这些职责标为视觉假设，按需要安排页数。

## 1. 定整套继承的规则与可变范围

先定一句视觉方向，说明这套作品靠什么建立识别度。再选 2–4 条贯穿全套的锚点，例如主对齐轴、字号层级、背景与强调色的角色、图片光线与裁切方式。把局部用法写在各自的版式下。

| 决策 | 记录方式 |
| --- | --- |
| 继承 | 写清具体关系、适用范围和来源。例如「同级对照图共用上缘，中央留出隔离带」，引用源稿页码和区域。优先采用反复出现的关系。单页证据支持该页型的观察，推广到其他页型时标为延展。 |
| 跨页延展 | 写清新页面职责、沿用的锚点、允许调整的参数和理由。可调整焦点位置与尺度、图文比例、信息密度、裁切或色彩面积。一次调整以该页职责为依据，并检查与相邻页的衔接。 |
| 待确认 | 把影响判断的未知项显式留下，例如只能从截图估计的字体，或缺少样本的高密度版式。列明暂用的占位或范围。 |

证据标签沿用 **实测 / 观察 / 归纳 / 延展 / 待确认**。约束强度单独记录。用户确认的品牌规范可以是硬约束，参考稿中实测到的数值仍可只是某个页型的默认值。对组件和素材同时记录视觉属性与使用职责，例如「细线方角框，用于界定同级信息」或「近景、侧光，用于揭示材质」。新稿素材可按同一职责选取。

## 2. 按页面职责匹配构图和元素

从新页面要让读者看懂什么出发，再找源稿中完成同类任务的构图。先判断视线从哪里进入、读者需要比较还是顺着读、证据应当占多大面积，再选局部元素。每个候选都注明来源页或区块。按[整页构图规则](page-composition.md)选择同样适合该职责的对齐、偏移与图像变体。

| 参考稿的构图或元素 | 适合的页面职责 | 迁移时检查什么 |
| --- | --- | --- |
| 大幅主图、短标题、大面积留白 | 开场，确立主题或情绪 | 保留一个主焦点和标题的落点。主图应承载主题。 |
| 同尺寸双栏、共用对齐轴、对称的分隔或框线 | 对照两项同级信息 | 两侧使用同一比较维度、视觉权重和阅读顺序。主次关系明确时可改为不等栏，并标明延展。 |
| 偏置近景、窄图文栏、局部标注 | 展示细节、证据或局部机制 | 裁切要露出关键部位，标注靠近对应细节，说明文字的面积服从焦点。 |
| 有顺序的列表、编号、层级框或表格 | 解释过程、步骤或多项证据 | 保留顺序和分组线索。逐步阅读可用轴线串联，同级比较可保留行列。先为图表、数据或说明预留槽位。 |
| 低密度色块、跨页反复出现的小图形或图像母题 | 转场、停顿或收束 | 转场用密度或明暗变化提示换段。结尾可缩小或重现开场母题，给最终落点留空间。 |

从 DOC/PDF 迁移时，先区分供连续阅读的页眉、长文和表格，与承担视觉表达的主图、分栏和层级。按目标画幅重组阅读单位，例如保留文档分栏的共同对齐轴，把单页长表拆为可独立理解的证据页。从 PPT 迁移时，先辨别母版、固定装饰和只在特定页型出现的构图，再按用途复用。目标媒介改变时，优先保住主次、阅读顺序与对齐关系，坐标和尺寸随画幅调整。

例如，源稿双图共用上缘，可继承到同级对照页。如果原稿的灰绿色只用于小色块，扩成满页转场就标为延展。说明它承担换段职责，并用原有留白和色彩角色约束用量。

## 3. 排整套构图与节奏

1. 先排职责，再排页面。标出观众需要建立整体印象、看局部、比较、停顿或回到全局的位置。总图之后的拆解页可沿用相同的色彩、编号或轮廓，回顾页再收回同一个视觉线索。
2. 分别标出叙事重要性、信息密度、画面的视觉强度，给每页指定第一眼落点。用缩略图查验实际强弱。需要观众记住总图时，应让它压过随后拆解页的装饰和大色块。密集解释后可用低密度页换气。相邻页有意改变焦点大小、位置、留白、明暗或对称性，同时保留共享锚点。
3. 用一张分镜表看全套。逐页记录「页序／视觉职责」「焦点、构图与槽位」「继承规则及来源」「延展与理由」「与前页的衔接及强度」。先横看全套焦点和强弱变化，再逐页检查视觉职责与构图是否匹配。另有预览请求时，用同尺度缩略图复查页面关系。

分镜检查通过的条件是每页职责和第一眼落点清楚，继承可追溯，延展有边界，相邻页面的变化或重复服务于段落转换和阅读顺序。文字分镜通过只代表规划检查，渲染与成品视觉表现另行验证。

需要换模型或换素材重放时，将总图、拆解定位与回扣绑定到同一个共享图形，并用[复现规范](reproducibility.md)锁定已评审的节奏与候选版式。
