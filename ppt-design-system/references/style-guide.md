# 从参考素材到 STYLE.md

## 采集证据

先记录参考范围和目标媒介。素材里的页框、水印和目录可能属于汇编者，照片、产品标签和包装可能来自另一套系统。分别标记来源，明确本次提炼的层。

| 输入 | 采集方式 | 证据地址与边界 |
| --- | --- | --- |
| PPTX | 用项目脚本读取原生对象、组合、标题对齐和背景。再看代表页的渲染，确认视觉层次、裁切和叠放。 | 页码、对象 ID、归一化坐标。原生属性与渲染冲突时保留差异。 预览转成 PDF 后仍以原始 PPTX 扫描对象和媒体。 |
| PDF | 先看缩略图和页型，再渲染代表页。可读时用文字和矢量对象核对字号、位置与色彩。扫描页按图片处理。 | PDF 文件页码与区域。渲染取色只代表该渲染结果。 |
| 图片 | 标记画布和主要区域，测量色彩、留白、轴线、层叠与图像角色。 | 文件名、像素或归一化区域。字号层级可估计，字体家族和源矢量结构通常待确认。 |
| 网页 | 查看用户给定 URL 的实际渲染。能读取页面结构时，结合样式计算值和可见组件；比较代表视口。 | URL、视口、状态、区域或选择器。单张截图只支持该视口和状态的观察。 |

先选代表性的页型或状态，记录覆盖范围。遇到反例时判断它是局部例外、不同变体，还是推翻了原来的规则。素材较少时保留窄范围的观察与建议，避免把单个案例表述成整套原规范。参考稿含多套视觉体系时，按[复现规范](reproducibility.md)登记主风格、辅助和排除范围。

## 决定哪些内容值得补齐

- **实测**　属性、坐标、色值或来源文件明确给出的值。标出采集方式和出处。
- **观察**　可从素材看到的关系，例如标题在图组之前、主体用暖灰背景。写清观察范围。
- **归纳**　从多个样本得出可复用规则。说明规则适用的页型和例外。
- **延展**　为新任务做的设计决策。先指出缺的是哪种页型、组件或状态，再从已确认的视觉角色推出一个做法。写出继承项、可变项和验证方式。新的数值可以作为起点或范围。
- **待确认**　会影响品牌身份或产出的未知，例如精确字库、印刷专色和正式标志变体。保留可用的替代方式并写明何时需要确认。

延展应补目标任务的缺口。可按需要补版式、密度、图文比例、窄屏重排、长文案或新增组件。选择变体时保持原稿有证据的阅读层级、用色角色、几何或图像处理。优先用少数通用规则推导变化，避免为每个示例另建一套规则。

## STYLE.md 的结构

采用[元素到页面的编译流程](element-compilation.md)时，`STYLE.md` 由底层元素目录、适配规则和可执行设计包共同生成。先写元素角色与使用条件，再写可组合的排版及编译验收。

1. **范围和快速套用**　目标、主要版式、必守项、可变项。
2. **视觉参数**　颜色角色、字体层级、对齐、留白、边框及图片用法。精确值与建议范围各自标记。图片记录其职责、主体位置、留字区、裁切、色彩或光线与替换条件。
3. **整页构图与组件**　按页型写出主焦点、主次区域、阅读顺序、对齐与偏移、图像角色、遮挡边界和容量变化时的调整方式。使用[整页构图规则](page-composition.md)标注证据与可变范围。
4. **延展规则**　每条记录目标情景、证据、继承的规则、可调整的参数及如何验收。
5. **检查与来源**　用一份新内容干跑选择版式、填入槽位、检查层级。多页视觉设计可按[视觉分镜流程](visual-storyboard.md)用页面职责和占位槽检查适配，另列整套共享的规则及逐页延展。列出具体证据位置、待确认项，以及实际完成的验证类型。

事实和规则可用编号互相引用。正文让下游快速找到该怎么做，证据表集中说明依据。若同一条规则只有局部证据，将它标成局部观察或延展。新稿验收关注阅读层级、与源风格的关系及内容适配。
